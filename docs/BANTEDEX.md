## 2. 模型点名（按 model name 正则匹配，注入一句小白话）

**匹配方式：正则，不是硬编码名。** 模型名带版本号且会滚动（Sonnet/Opus 已到 5.x、GPT 已到 6、Claude 还有 4.x 等），硬编码"Claude Sonnet"会漏掉"Claude Sonnet 4.5 / 5.0"。规则：
- **大小写不敏感**（用 `/.../i`）。
- **对模型名字符串做正则匹配**（命中子串即可），不是精确相等。
- **按下列顺序自上而下匹配，取第一个命中**（更具体的在前）。
- 匹配对象**只能是"模型"**——tokens.ci 的 model 分布里是模型名；**CodeBuddy / Cursor / Cline / WorkBuddy 这些是"客户端/宿主"，不是模型，永远不会出现在 model 名单里，不要给它们写"模型标签"**（那是给 host 的，不是给 model 的）。

当某个 model name 命中某类时，随机挑一句"贴标签"：

| 正则（/i） | 命中示例 | 贴标签 |
|---|---|---|
| `/(?:claude[ -])?(?:opus|sonnet|haiku)/` | Claude Opus 4.5、Claude Sonnet 5 | 「Anthropic 主力，干的全是硬活，就是贵了点」 |
| `/gpt[- ]?[0-9]/` | GPT-6、gpt-4.1、GPT-4o | 「快是真快，烧起来也快」 |
| `/gemini|google/` | Gemini 2.5 Pro、Gemini | 「谷歌的长期投资，你也在为它的未来买单」 |
| `/grok|xai/` | Grok 4 | 「马斯克同款佛系套餐」 |
| `/deepseek|qwen|kimi|glm|doubao|moonshot|siliconflow/` | DeepSeek-V3、Qwen3、Kimi | 「国货之光，钱包友好型功德」 |
| `/llama|qwen2?\.5?[- ]?coder|mistral|local|ollama|vllm/` | Llama 3.3、本地跑 | 「这是你的私人佛堂，不入赛博公共功德榜」 |
| `/o[1-9]|reasoning/` | o3、o4-mini | 「推理上头型，想得比写得多」 |
| 其它（未命中） | — | 「你的小众搭子，名字我都念不全」 |

> **注意**：正则命中的是 model name；host（客户端）名如 CodeBuddy/Cursor/Cline 不要混进来。真正播报里出现的"谁在用"，tokens.ci 会把**客户端名**与**模型名**分开给——客户端名归"用了哪些工具"，模型名才归这条"模型点名"。

## 3. 数字换算梗（token → 让人"噗"的单位）

## 5b. 纯梗收尾（自启动时无具体数字可用 → 不打断、不追问，只送祝福）

场景：自动收尾时 Tier 1/2 都读不到数。此时**不反问用户**，直接给一段不含具体数字的轻量赛博功德祝福，收个尾即可。任选其一或拼接：

- 「今天这一程的赛博功德，已由本黄豆代为念诵：辛苦了，NEVERMIND。」
- 「数不清你今天烧了多少，不重要——反正都记在你头顶的功德簿上了。收工，NEVERMIND。」
- 「读不到数？无所谓。今天的你值得一句：NEVERMIND，明天再战。」
- 「功德满不满不在乎，活是真的干完了。NEVERMIND。」
- 「（读不到 token 时）赛博功德结算失败？不，这叫——缘，妙不可言。NEVERMIND。」
