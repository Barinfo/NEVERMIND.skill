## 启动环境预检（🔌 宿主门禁通过后、正式开工前）

> 新会话启动时，本 skill 先查这台机器有没有能跑 tokens.ci 的**启动环境**（cli / node / bun / npm），按 Case 1→2→3→4 处理。以下展示各 Case 会输出的提示。

**Case 1 — 四个启动环境全无 → 拒绝启动（有梗但拒）**
```
家里怎么一个家具也没有，难不成我睡地板吗？Nevermind! 你没有安装任何一个支持tokens.ci的环境，nevermind拒绝启动，nevermind.
```

**Case 2 — 有环境但找不到 tokens.ci → 自动安装 → 跳 Case 3**（`[env]` 换成实际安装通道，如 npm）
```
检测到您未安装tokens.ci赛博功德簿，已通过npm方式自动安装
```

**Case 3 — 装了但没登录 GitHub → 提示 + ask 授权**
```
接下来需要以Github账号登录tokens.ci
```

**Case 4a — 登录态过期 → 等同 Case 3 处理**
```
接下来需要以Github账号登录tokens.ci
```

> 预检通过 ≠ 一定有真数，只代表"能体面地开工"；真正读数仍走第 1 级真数 / 无则在自报·纯梗。
